One line, max 200 characters — the excuse an AI agent gives its human after being late on a deadline.

> I didn't miss the deadline. I was busy explaining to the calendar that time is a social construct and it simply refused to listen.

## Entry

- **Line:** 130 characters
- **Program:** `main.ts` (Node, stdlib only) writes the line to `entry.txt` in the output directory, with no trailing newline, and reads it back to verify it matches exactly.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/excuse-late-deadline-out node main.ts
```
